# SkyOps Drone Intelligence Dashboard 
SkyOps Drone Intelligence Dashboard is a full-stack web application designed for Drone-as-a-Service operations. The platform allows users to manage drone fleets, create and monitor missions, visualize sensor data, track drone status, and review alerts across use cases such as agriculture monitoring, wildfire detection, technical inspections, wildlife monitoring, and relief/rescue operations.

The project uses React and TypeScript for the frontend, Django REST Framework for the backend, PostgreSQL for structured data storage, and Recharts/D3.js for interactive data visualization. Since the project is built as a portfolio application, drone and sensor data are simulated to demonstrate real-world dashboard functionality, API integration, data modeling, and full-stack architecture.
